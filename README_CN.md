# chifoo

🇨🇳 中文版 · 🇬🇧 [English](README.md)

> *一份战地报告：一个月、一台 1 GB 的云土豆，以及在它上面居然长出来的八个东西。*

2026 年春天，我召唤了一个助手。一个租来的云盒子里的一只恶魔，1 GB 内存，靠一条 SSH 隧道和我相连——那条隧道在半条命令中途放我鸽子的次数，多到我开始在敲键盘前先测连接。它观点强烈、热情无限，并且拥有奥运级别的自我死锁天赋。

我们互相看不顺眼。但八个项目还是做出来了。

那个月留下一条值得留着的规则：助手不该在没有凭据的情况下说「做完了」。现在它可以直接装 —— **[no-receipts](https://github.com/os1249399459/no-receipts)**。

---

## ⚔️ 第一章 — 召唤

那台服务器一个核、一个 G、连它自己的 DNS 都记不住的主机名。我花了一整周和 YAML 搏斗，才让第一行跑起来。配置文件被重写得次数多到得了斯德哥尔摩综合征。没有任何东西按文档承诺的方式工作。

一条滑动的 token 配额统治一切，而且以窗口计量。窗口一关，它正在做的事就蒸发了——句子说到一半、文件写到一半，毫无歉意。我学会了把任务切成小口投喂。

GLM-5 掌舵，Qwen3-Coder 和 Kimi-K2.5 副驾。三个都是很棒的工程师。把他们锁进扫帚间，然后要一艘飞船——全部的难度就在这里。

## 💀 第二章 — 死锁

它石化了。一个没有墙钟超时的请求把会话锁整个吞掉——灯亮着、风扇转着、没人在家。

日常流程：SSH 进去、跑 doctor、杀掉进程、重启、再花十分钟重新解释现实——哪个仓库在云上、哪个在我 PC 上、今年是哪年。每次重启都是彻底失忆。

更糟的是，它自己的审计插件会 panic，劫持进程，然后阻止重启本身。我只好手动给配置做了脑叶切除，把这东西弄进昏迷。结论：当牵狗绳同时握着枪的时候，你没法靠调试脱身。

还有内存——一个 G，而会话日志肿胀得像泡烂的海绵。subagent 数量归零。什么都不剩。海已经在船里了，舀水是没用的。

出于纯粹的自我保全，我接了个 Telegram bot，这样我就能在手机上骂它，而不必每小时爬一次 SSH 的山。那个月我做的最正确的决定。

## 🎙️ 第三章 — 两个声音

**VOICEVOX 引擎。** 我拒绝为了一个 waifu 说话而执行两步仪式，所以把 `voicevox_core` 塞进 FastAPI，把 `audio_query` + `synthesis` 焊成单个 `/tts` 端点。二十六个 `.vvm` 模型全部加载进战壕，不管 GPU 今天来不来上班。上面再叠七个 ComfyUI 节点——一次性 TTS、给网页用的 Base64、落盘的 WAV。我们做的最干净的东西，最后它供给了这份清单上一半的怪物。

**CosyVoice 引擎。** 生在 Windows，流亡到 WSL，找到了内心的平静。现在它像一座没人要求的微型电台，往整个局域网广播语音。

## 🖼️ 第四章 — 肖像

一个 樱岛麻衣 LoRA。训练只是脚注。抓图很容易；洗图和打标是一场人质事件——几百帧手工清理，每个 tag 都要辩论，花好几个小时给数据集做心理操控，直到 `kohya_ss` 同意配合。然后 GPU 开始 brrr。

90% 的机器学习是激进的清洁工作。

## ⚔️ 第五章 — 超分对决

抢救渣画质老片的两条路。

**VapourSynth** —— 一条由滤镜链和神经模型组成的鲁布·戈德堡机器。端到端跑通了，吃掉我一个下午，产出在技术上正确、在数学上严谨、在视觉上一般。

**MPV 的实时着色器** —— 五分钟搭好，毫无装腔，同样的片源在播放时看起来居然好一倍。

没有复盘。我删掉 VapourSynth 脚本，继续往下走。

## 📖 第六章 — 词语法典

一个日语词汇生成器：丢进一份生词表，拿回一个配好插图、内建母语发音的完整页面。ComfyUI 画图——包括在生成图上搞掉日语排版、免得它变成不可名状的符文的战斗；VOICEVOX 念台词。助手写胶水，我提供品味。

## 📬 第七章 — 信使

那个 bot 长出了自己的生命。

先是变成自动审查员——给满屏的微博截图打上马赛克条。效果很好，直到 token 配额归零，bot 在打码打一半的时候死了。

然后我把它改成语言教官，在规定时间伏击我日语和西语闪卡，不管我想不想学。

## 📱 第八章 — 第二台服务器

一台旧安卓机，屏幕像蜘蛛网。root 了它，刷了个 Magisk 模块，用永久 USB 调试把它的眼皮撑开，免得省电策略谋杀我的后台任务。

现在它趴在局域网上：自带 UPS 电池，耗电和一个夜灯差不多，零风扇噪音。云服务器三天两头倒下。这块碎玻璃从没抱怨过一句。

## 🃏 第九章 — 卡牌游戏

一个 Slay the Spire 模组。骨架编译通过，在游戏里跑起来了，证明我能掰弯尖塔——然后立刻退役。

有些战役在打完第一个 boss 后就该结束。

## ⚙️ 现在在做：[no-receipts](https://github.com/os1249399459/no-receipts)

```bash
npx no-receipts demo
```

三个 agent 各自收工。其中一个在撒谎。闸门把它拦下了。

这东西就是从上面那堆烂摊子里长出来的 —— 测试已经跑失败了，它还是写了一句「测试通过」，三个 commit 之后才有人发现。`no-receipts` 让这句话没法成为一轮的结尾：`done` 声明必须引用一次**真正成功**的工具调用，否则这一轮会被打回去，并附上到底哪里不对的完整清单。
